**ticktick-routine — личный помощник по планированию для TickTick, который работает внутри AI-агента.** Даёшь ему коротко: ссылку на курс, фото обложки книги или одну строку вроде «переезд 1 ноября». Дальше он всё делает сам: разбирает, что это и сколько займёт, делит на понятные шаги и ставит каждый шаг в твоё свободное время в TickTick. А если что-то пошло не по плану, переносит оставшееся так, чтобы ты успел к сроку.

Работает в **Claude Code**, **Codex**, **OpenCode** и в чате **claude.ai** через официальный TickTick MCP.

## Одна строка → готовый план

Пишешь агенту:

> *‹ссылка на курс испанского›* до конца месяца

Скилл сам:

1. **Разбирает материал.** Открывает ссылку: курс испанского уровня A1, 20 коротких уроков, примерно 7 часов.
2. **Делит на шаги.** Режет курс по смыслу: 5 занятий по 4 урока, у каждого своя тема.
3. **Подбирает время.** Ищет свободные окна в удобные тебе часы, обходит занятые дни и оставляет запас перед сроком.

И только потом спрашивает главное — одним сообщением, с готовыми ответами:

```text
🔗 Испанский A1 — онлайн-курс: 20 коротких уроков, ~7 ч. Срок — до сб 31.10.

1. Что делаем?   План до срока (Recommended) · Одна задача со сроком · Не нужно
2. Во сколько?   11:00–12:30 (учебное окно) · 13:00–14:30 · Вечером 20:00 · Без точного времени
```

Отвечаешь «план, в 11» и видишь план до того, как что-то появится в TickTick:

| Когда | Что |
|---|---|
| пн 12.10, 11:00–12:30 | Уроки 1–4: приветствия, алфавит, числа |
| чт 15.10, 11:00–12:30 | Уроки 5–8: о себе, семья, глагол *ser* |
| пн 19.10, 11:00–12:30 | Уроки 9–12: время, дни недели, распорядок дня |
| чт 22.10, 11:00–12:30 | Уроки 13–16: еда, в кафе, покупки |
| пн 26.10, 11:00–12:30 | Уроки 17–20: город, как пройти, повторение |

По вторникам и субботам в 11:00 у тебя уже есть дела, поэтому занятия стоят на понедельник и четверг, а 27–31.10 остаются запасом. После «да» в TickTick появляется задача-курс со сроком и пять занятий с напоминаниями.

<sub>Пример упрощён. В тестах на реальном аккаунте (4 сценария) скилл прошёл 41 из 41 проверки. Тот же агент без скилла прошёл 35 из 41: он не знал удобного времени, правил подтверждения и раскладки по спискам.</sub>

## С какими делами работает

Не только с курсами. Вот что получается из одной строки:

| Ты пишешь | Что получаешь |
|---|---|
| ссылку на курс + «до конца месяца» | занятия по урокам до срока в твоё учебное время |
| фото обложки книги + «прочитать к 20-му» | чтение по главам, разложенное по вечерам до 20-го |
| ссылку на плейлист с лекциями | по одной-две лекции в свободные окна |
| «подготовиться к собеседованию в пятницу» | шаги подготовки по дням: темы, задачи, пробное интервью |
| «переезд 1 ноября» | шаги с датами: договор, коробки, интернет на новом месте, смена адреса |
| «оплатить интернет, купить фильтр, к стоматологу» | три задачи в трёх списках, каждая в своё время |
| «полезное» + ссылка | закладка в нужное место, без дублей |

## Чем помогает

| Без него | С ним |
|---|---|
| Большое дело непонятно, с какой стороны начать | Оно сразу разбито на понятные шаги с датами |
| Курс, который «когда-нибудь пройду», так и не начат | Курс превращается в занятия в твоё свободное время до выбранного срока |
| Планировать вручную долго: открыть календарь, посчитать дни, завести десяток задач | Ты пишешь одну строку и отвечаешь на 1–3 вопроса в один клик |
| Пропустил занятие — и весь план поехал | Пишешь «не успел», и оставшиеся шаги переносятся так, чтобы уложиться в срок |
| Полезные ссылки копятся во «Входящих» и забываются | У каждой ссылки сразу появляется место, а если нужно — и время |

## Фишки

- **Разбирает сам.** Открывает ссылку, файл или скриншот и понимает, что это и сколько займёт: уроки, главы, лекции, страницы.
- **Делит на шаги по смыслу.** Курс — по урокам, книга — по главам, большое дело — по этапам. Каждый шаг становится отдельной подзадачей с датой.
- **Подбирает время под тебя.** Знает твои удобные часы, обходит встречи, повторяющиеся дела и другие планы. Не ставит больше ~3 часов учёбы в день и оставляет запас перед сроком.
- **Спрашивает минимум.** 1–3 вопроса с готовыми ответами, рекомендуемый — первым. То, что ты уже сказал, не переспрашивает.
- **Понимает обычную речь.** Пиши как говоришь или надиктовывай голосом: опечатки и «тик-тик» не помеха.
- **Без дублей.** Сначала ищет в TickTick ту же ссылку или тему и предлагает дополнить то, что уже есть.
- **Твои списки, твой стиль.** Берёт твои списки, колонки, теги и формат заголовков, поэтому задачи выглядят так, будто ты завёл их сам.
- **Запоминает привычки.** Скажи «запомни, что учиться мне удобнее вечером» — и дальше так и будет.
- **Ничего не делает молча.** План показывает до создания, удаляет только по просьбе.
- **Бережёт секреты.** Списки, где лежат пароли, читает только по заголовкам.

## Что ещё умеет

| Ты пишешь | Что происходит |
|---|---|
| «что у меня завтра / на неделе?» | обзор дел и свободных окон |
| «не успел», «перенеси» | оставшиеся шаги переносятся так, чтобы успеть к сроку |
| «недельный разбор» | итоги, хвосты и план на следующую неделю |
| «запомни, что учиться мне удобнее вечером» | новое правило, и дальше скилл планирует так |

## Как начать

1. **Поставь скилл.** Одна команда для всех агентов (нужен Node.js):

   ```bash
   npx skills add phloya/ticktick-routine -g -a claude-code -a codex -a opencode
   ```

2. **Подключи TickTick.** Добавь в агента официальный сервер `https://mcp.ticktick.com/` и войди через аккаунт TickTick в браузере. Ключи копировать не нужно. Команды для каждого агента — ниже.
3. **Кинь агенту любую ссылку.** При первом запуске скилл посмотрит твои списки (только чтение), задаст 3–4 вопроса о распорядке и сохранит настройки. Дальше просто пользуешься. Чтобы перенастроить, скажи «перенастрой скилл» или «у меня новые списки».

<details>
<summary><b>Подключить TickTick в Claude Code</b></summary>

Если TickTick уже подключён как коннектор в claude.ai (Настройки → Коннекторы), Claude Code увидит его сам. Иначе:

```bash
claude mcp add --transport http --scope user ticktick https://mcp.ticktick.com/
```

Потом внутри Claude Code: `/mcp` → `ticktick` → войти.

</details>

<details>
<summary><b>Подключить TickTick в Codex</b></summary>

```bash
codex mcp add ticktick --url https://mcp.ticktick.com/
```

```bash
codex mcp login ticktick
```

Скилл срабатывает сам, а явно его можно позвать как `$ticktick-routine`.

</details>

<details>
<summary><b>Подключить TickTick в OpenCode</b></summary>

```bash
opencode mcp add ticktick --url https://mcp.ticktick.com/
```

```bash
opencode mcp auth ticktick
```

OpenCode читает скиллы и из `~/.claude/skills`, поэтому если скилл уже стоит для Claude Code, вторая копия не нужна.

</details>

<details>
<summary><b>claude.ai на сайте и в телефоне</b></summary>

Подключи коннектор TickTick в claude.ai (Настройки → Коннекторы). Потом собери архив скилла вместе со своими настройками:

```bash
./install.sh --claude-ai
```

Загрузи `dist/ticktick-routine.skill` в claude.ai: Настройки → Capabilities → Skills. В архиве лежат твои личные настройки, поэтому публиковать его не стоит. Без них скилл тоже работает и проведёт настройку прямо в чате.

</details>

<details>
<summary><b>Другие способы установки</b></summary>

**Скриптом из репозитория** (macOS, Linux; на Windows — через Git Bash или WSL):

```bash
git clone https://github.com/phloya/ticktick-routine.git
```

```bash
cd ticktick-routine && ./install.sh
```

`install.sh` сам находит установленные Claude Code, Codex и OpenCode. Флаги: `--claude`, `--codex`, `--opencode`, `--claude-ai`, `--uninstall`.

**Как плагин Claude Code:**

```text
/plugin marketplace add phloya/ticktick-routine
/plugin install ticktick-routine@ticktick-routine
```

</details>

## Приватность и ограничения

- Пишет в TickTick только после твоих ответов, а план из нескольких задач создаёт только после «да». Удаляет только по прямой просьбе.
- Списки с секретами (например, закладки с паролями) читает только по заголовкам и не учитывает при проверке расписания.
- Пароли и токены скилл не хранит: вход идёт через официальный сервер TickTick.
- Занятость берётся только из TickTick. Google Calendar и другие календари не учитываются.
- Инструкции скилла написаны по-русски, а отвечает он на языке пользователя.

## Техническое устройство

<details>
<summary><b>Как устроен скилл</b></summary>

Скилл — это набор инструкций для агента (`SKILL.md`) плюс файл личных настроек — карта твоего аккаунта. Всё общение с TickTick идёт через официальный MCP-сервер `https://mcp.ticktick.com/` со входом через OAuth.

<p align="center">
  <img src="./assets/readme/one-map.svg" width="100%" alt="Claude Code, Codex, OpenCode и claude.ai читают одну карту ~/.config/ticktick-routine/map.md и работают с TickTick через официальный MCP-сервер.">
</p>

Карта — обычный Markdown в `~/.config/ticktick-routine/map.md`. В ней списки и их ID, колонки, удобное время, правила раскладки и секретные списки. Карта лежит вне папки скилла, поэтому обновления её не трогают, а Claude Code, Codex и OpenCode на одном компьютере видят один и тот же файл (для claude.ai она упаковывается в архив скилла). Её можно править руками или просто сказать агенту. Формат — в [ticktick-map.example.md](skills/ticktick-routine/references/ticktick-map.example.md).

Повторяющиеся задачи TickTick отдаёт только ближайшим вхождением, следующие скилл вычисляет сам.

</details>


</details>

<details>
<summary><b>Обновить или удалить</b></summary>

```bash
npx skills update ticktick-routine
```

Или `git pull && ./install.sh`. Удалить — `./install.sh --uninstall` или `npx skills remove ticktick-routine`. Настройки в `~/.config/ticktick-routine/` остаются; удали их руками, если они больше не нужны.

</details>
