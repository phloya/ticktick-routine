# Карта TickTick — шаблон

> Это пример. Скилл заполняет его при первом запуске (`references/setup.md`) и сохраняет в `~/.config/ticktick-routine/map.md`. Все ID ниже выдуманы — в реальной карте они берутся только из ответов TickTick API.

Снимок от <ГГГГ-ММ-ДД>. Списки могут меняться — сверяйся с `list_projects`.

## Профиль

- **Часовой пояс:** Europe/Moscow, UTC+3. Все даты — со смещением `+0300`.
- **Язык задач:** русский.
- **График:** работа пн–пт 10:00–19:00.
- **Учёба:** удобнее всего 20:00–22:00 в будни и 11:00–14:00 в выходные — предлагай эти окна первыми.
- **Быт:** вечер (19:30–21:00) или выходные днём; спрашивай.
- **Ритм дня:** подъём ~8:00, без просьбы не ставь ничего раньше 9:00 и позже 23:30.
- **Фиксированное:** спортзал пн/ср/пт 19:00–20:00; «Недельный разбор» — вс 18:00 (повторяющаяся задача).
- **Подтверждение:** план из нескольких задач — показать и ждать «да»; одна задача — создавать сразу.
- **Секретные списки:** 🔖 Закладки — там есть доступы; только заголовки, в запросы расписания не включать.
- **Не предлагать без просьбы:** фокус-сессии (Pomodoro).

## Куда что класть

| Материал | Куда | Тип |
|---|---|---|
| Курс, хендбук, лекции, туториал «пройти» | 🎓 Учёба → Сейчас (есть срок) / Очередь (без срока) | TEXT, план подзадачами |
| Сервис, утилита, приложение | 🔖 Закладки → 🧰 Инструменты | NOTE без даты |
| Гайд, статья-инструкция, репозиторий-пример | 🔖 Закладки → 📚 Гайды | NOTE без даты |
| Дизайн, вдохновение | 🔖 Закладки → 🎨 Идеи | NOTE без даты |
| Книга, фильм, аниме | 📺 Контент → В очереди + тег | NOTE |
| Дом, оплата, документы | 🏠 Дом | TEXT, дата и время |
| Купить | 🛒 Покупки | TEXT, без даты, если не срочно |
| Врач, анализы, спорт | 🏃 Здоровье | TEXT, дата и время |

Спорные случаи: статья «прочитать к сроку» — если это учёба, задача в 🎓 Учёба; если просто полезное — закладка с датой и напоминанием.

## Как оформлять

- **Учебный план:** родитель `Пройти <материал>` · Учёба / Сейчас · `priority: 3` · весь день на дату дедлайна с напоминанием утром; занятия — подзадачи блоками времени с напоминанием в начале (`TRIGGER:PT0S`), в `content` — что пройти и ссылка на раздел; у последнего занятия в заголовке `(дедлайн <дн> <д.мм>)`.
- **Закладка:** NOTE без даты, заголовок — коротко, что это делает; в `content` первой строкой ссылка, ниже 1–2 строки, зачем.
- **Контент:** NOTE, книги в «ёлочках», один тег, колонка «В очереди».
- **Дом и здоровье:** TEXT, заголовок с глагола («Оплатить интернет»), дата + время + напоминание; регулярное — с `repeatFlag`.
- **Покупки:** TEXT, просто название вещи, ссылка на товар — в `content`.
