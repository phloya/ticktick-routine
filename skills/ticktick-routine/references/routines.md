# Режимы рутины

Все три режима сначала читают данные, а меняют задачи только после «да» — это правки сразу нескольких задач.

Как читать расписание во всех режимах: `list_undone_tasks_by_date` (до 14 дней за вызов) с `client_timezone` из карты и `projectIds` — все списки из `list_projects`, кроме секретных из карты. `list_undone_tasks_by_time_query` по спискам не фильтрует и тянет заметки вместе с содержимым — при секретных списках им не пользуйся. Повторяющиеся задачи в выдаче видны только ближайшим вхождением: дальше разворачивай их по `repeatFlag` сам.

## Обзор дня или недели

Триггеры: «что у меня сегодня / завтра / на неделе», «когда я свободен», «есть время на учёбу?».

1. Возьми задачи на нужный период (сегодня / завтра / неделя) так, как описано выше, и разверни повторяющиеся.
2. Сгруппируй по дням. Внутри дня: сначала блоки со временем по порядку, потом «на весь день». Просроченное — отдельно сверху.
3. Покажи свободные окна, в первую очередь в удобных окнах из профиля карты. Занятость считай по правилам из Шага 3 SKILL.md: блоки со временем, фиксированные блоки профиля, учебные задачи «на весь день» съедают ~1.5 ч окна.
4. В конце одной строкой предложи действие: «Перенести что-то или поставить занятие в свободное окно?»

Формат — коротко, без содержимого заметок:

    📅 Неделя 5–11 окт
    Просрочено: «Записаться на курс» — вт 29.09
    пн 5.10 · дел нет · свободно 11:00–15:00
    вт 6.10 · весь день: Python 3.1–3.2 · свободно ~12:30–15:00
    …
    вс 11.10 · 16:00 Недельный разбор · дедлайн: хендбук Python

## Перенос просроченного и пересборка плана

Триггеры: «не успел», «перенеси», «сдвинь план», «заболел, всё сдвинь», найденные просрочки.

1. Найди задачи: незавершённые за последние 7 дней по текущий момент (как описано выше) — всё, у чего срок уже прошёл; конкретную задачу — через `search_task`.
2. **Разовая задача** → предложи ближайший подходящий слот: учёба — в учебном окне, быт — в бытовом или спросить.
3. **Занятие из плана** (есть `parentId`) → пересобери оставшиеся занятия до дедлайна родителя: сохрани порядок частей, держи не больше ~3 ч учёбы в день. Если не помещается — предложи выбор: сдвинуть дедлайн (тогда поменяй и родителя), удлинить занятия или объединить части.
4. Покажи таблицу «было → стало» и жди «да».
5. Примени `batch_update_tasks`: `startDate`, `dueDate`, `reminders`, а также пометки «(до …)» / «(дедлайн …)» в заголовках — они должны совпадать с новыми датами.
6. Отчёт в одну-две строки.

## Недельный разбор

Триггеры: «недельный разбор», «итоги недели», напоминание задачи недельного разбора (если она есть в карте).

1. **Итоги:** `list_completed_tasks_by_date` за последние 7 дней с теми же `projectIds` → что сделано, по спискам. Прогресс учебных планов: выполнено X из Y занятий.
2. **Хвосты:** просроченное — одним списком с предложением переноса (как в режиме выше).
3. **Неделя вперёд:** задачи на 7 дней вперёд (как описано выше) → перегруженные дни и свободные окна.
4. **Очереди:** что лежит в очередях учёбы и контента. Если есть свободные окна — предложи взять 1–2 вещи в работу.
5. **Inbox:** если там что-то появилось — разложи по шагам 1–4 SKILL.md.
6. В конце спроси, отметить ли задачу недельного разбора выполненной (`complete_task`) — следующий повтор поставится сам.
